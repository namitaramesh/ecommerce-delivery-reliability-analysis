# E-commerce Delivery Reliability Analysis

A Python and SQL analysis of delivery reliability patterns in a public e-commerce dataset.

## Project question

Where and when are e-commerce delivery promises most likely to be missed, and how do delivery delays vary by product category, location, order value, and seller-customer relationship?

## Project scope

This project analyses completed e-commerce orders using several connected data tables, including orders, order items, customers, sellers, products, payments, and customer reviews.

The project focuses on descriptive analysis rather than machine learning. It will use Python, Pandas, advanced SQL, and visualisation to investigate patterns in late deliveries.

## Skills being developed

- Python, Pandas, and NumPy
- Multi-table data cleaning and merging
- SQL joins, CTEs, and window functions
- Date and time calculations
- Data visualisation
- Reproducible analysis with Git and GitHub
